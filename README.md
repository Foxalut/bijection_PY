# Метод бисекции (деления отрезка пополам)

## Описание программы
Консольная программа на языке **Python**, предназначенная для поиска приближённого корня нелинейного уравнения с заданною точностью. 

В качестве целевой функции используется кубическое уравнение:
$$f(x) = x^3 - x - 2$$

Программа производит вычисления на отрезке $[1; 2]$ с точностью $\varepsilon = 0.0001$. Результат выводится в консоль.

---

## Описание алгоритма

Метод бисекции основан на теореме о промежуточных значениях непрерывной функции. Алгоритм состоит из следующих шагов:

1. **Инициализация:** Задаются начальные границы отрезка $a$ и $b$, а также требуемая точность $\varepsilon$.
2. **Проверка знаков:** Проверяется условие $f(a) \cdot f(b) < 0$. Если условие не выполняется, корень на данном отрезке не может быть гарантированно найден описанным способом.
3. **Деление пополам:** Вычисляется середина отрезка $c$:
   $$c = \frac{a + b}{2}$$
4. **Проверка точности:** Если длина текущего отрезка пополам меньше либо равна заданной точности ($\frac{b - a}{2} \le \varepsilon$), то вычисления прекращаются, а за корень принимается значение $c$.
5. **Выбор нового отрезка:** 
   - Если $f(a) \cdot f(c) < 0$, то корень находится на левой половине, поэтому правая граница смещается в точку $c$ ($b = c$).
   - Иначе корень находится на правой половине, и левая граница смещается в точку $c$ ($a = c$).
6. **Цикл:** Шаги 3–5 повторяются до тех пор, пока не будет достигнута заданная точность.
